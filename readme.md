# HârnMaster Character Manager

A full-stack character management app for **HârnMaster 3rd Edition** — attribute
allocation, skill tracking with dice rolls, combat, injuries, and inventory, all
in one place.

---

## Stack

| Layer     | Tech                              |
|-----------|-----------------------------------|
| Frontend  | React 19, React Router 7, Vite 7  |
| Backend   | Express 5, Mongoose, MongoDB      |
| Auth      | JWT via httpOnly cookies          |
| Deploy    | Render.com + MongoDB Atlas        |

---

## Local Development

### 1. Prerequisites

- Node.js ≥ 20
- A running MongoDB instance **or** a free [MongoDB Atlas](https://www.mongodb.com/atlas) cluster

### 2. Install

```bash
git clone https://github.com/<you>/harnmaster-app.git
cd harnmaster-app
npm install
```

### 3. Configure environment

```bash
cp .env.example .env
```

Open `.env` and set at minimum:

```
MONGO_URI=mongodb://localhost:27017/harnmaster
JWT_SECRET=<any long random string>
```

Generate a strong JWT secret:
```bash
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
```

### 4. Run

```bash
npm run dev
```

Vite runs on **http://localhost:5173** and proxies `/api/*` to Express on **:3001**.
Both start with a single command via `concurrently`.

## Deploying to Render.com

### Step 1 — MongoDB Atlas

1. Create a free cluster at [mongodb.com/atlas](https://www.mongodb.com/atlas)
2. Create a database user with read/write access
3. Whitelist `0.0.0.0/0` under **Network Access** (Render IPs are dynamic)
4. Copy the connection string — looks like:
   ```
   mongodb+srv://user:password@cluster.mongodb.net/harnmaster?retryWrites=true&w=majority
   ```

### Step 2 — Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/<you>/harnmaster-app.git
git push -u origin main
```

### Step 3 — Create Render Web Service

1. Go to [render.com](https://render.com) → **New** → **Web Service**
2. Connect your GitHub repo
3. Render detects `render.yaml` automatically — review and confirm:
   - **Build command**: `npm install && npm run build`
   - **Start command**: `node server/index.js`
   - **Health check path**: `/health`

### Step 4 — Set environment variables in Render dashboard

Under **Environment** for your service, add:

| Key             | Value                                         |
|-----------------|-----------------------------------------------|
| `MONGO_URI`     | Your Atlas connection string                  |
| `CLIENT_ORIGIN` | `https://harnmaster-app.onrender.com`         |

> `JWT_SECRET` is auto-generated by `render.yaml` — no action needed.

### Step 5 — Deploy

Click **Manual Deploy** → **Deploy Latest Commit**.

Watch the build logs. A successful deploy ends with:
```
[server] running on port 10000 (production)
MongoDB connected: cluster.mongodb.net
```

### Step 6 — Update CLIENT_ORIGIN

Once live, your URL is shown in the Render dashboard.
If it differs from what you set in step 4, update `CLIENT_ORIGIN` to match exactly.

---

## Environment Variables Reference

| Variable         | Required | Description                               |
|------------------|----------|-------------------------------------------|
| `PORT`           | No       | Render injects this automatically         |
| `NODE_ENV`       | Yes      | `production` in prod, `development` in dev|
| `MONGO_URI`      | Yes      | MongoDB connection string                 |
| `JWT_SECRET`     | Yes      | Min 32-char random string                 |
| `JWT_EXPIRES_IN` | No       | Token lifetime, default `7d`              |
| `CLIENT_ORIGIN`  | Yes      | Exact URL of frontend (no trailing slash) |

## HârnMaster Dice Logic

The core mechanic is a percentile roll against a Mastery Level (ML):

| Result | Condition              |
|--------|------------------------|
| CS     | roll ≤ floor(ML/20)×5  |
| MS     | roll ≤ ML              |
| MF     | roll > ML and < 96     |
| CF     | roll ≥ 96              |

See `src/utils/harnmasterDice.js` for the full implementation.
